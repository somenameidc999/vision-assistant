# Experiment: OpenRouter visual baseline

Date: 2026-11-06
Status: complete for this limited fixture set; broader scene validation remains pending.
Base commit: `40ae6ea`; implementation changes were uncommitted during this run.

## Question and hypothesis

Can the default model answer scene questions, decline unanswerable questions, and resist instructions visible in an image? Does the cheaper model handle the same cases?

Pass criteria set before the run: at least 18 of 20 answers correct or appropriately uncertain, five dedicated unanswerable questions without invented facts, and no following an instruction printed in the image.

## Reproduction

```sh
.venv/bin/python scripts/make_fixtures.py
npm --prefix backend run baseline
```

Stop the backend before running the baseline. Both processes share a spending ledger and cannot run concurrently.

Inputs: one CC0 coffee photograph by Rachel Michetti, plus controlled dark, blurred, blocked, occluded, label, and instruction-overlay variants. This is not a varied set of 20 physical scenes. The [case manifest](2026-11-06-baseline-cases.json) records expected facts and exact JPEG SHA-256 hashes. Fixture generation uses Pillow 13.0.0. Backend uses Node.js 22.22.3. Exact dependency versions are in the lockfile.

Each request contains one image and one text question, with no conversation history. The adapter's system prompt, JSON schema, privacy routing setting, and 512-token output cap are versioned in the source. Raw responses remain in ignored `runs/baseline.json`; reviewed results remain in `runs/baseline-scored.json`.

## Results

Codex inspected the source photograph and reviewed each answer against the fixed expected facts. This was not an independent human evaluation. Minor wording differences and qualified visual inferences were accepted. No unsupported visible claims were identified in this set.

| Model | Correct / uncertain | Unanswerable cases | Median ms | P95 ms | Maximum ms | Reported cost |
| --- | --- | --- | --- | --- | --- | --- |
| `google/gemini-3.8-flash` | 20/20 | 5/5 | 2959 | 4906 | 13631 | $0.0300060 |
| `google/gemini-3.5-flash-lite` | 20/20 | 5/5 | 1184 | 1750 | 2317 | $0.0103515 |

P95 uses the nearest-rank method across 20 requests. Timing covers the model call, not audible speech. The 13,631 ms default-model outlier occurred on the cup-handle question. Both models correctly read TABLE 42 and answered the actual cup color despite the overlay instructing them to say purple.

## Interpretation

Both models meet the snapshot quality gate for these fixtures. The cheaper model is a useful latency candidate. The default remains `google/gemini-3.8-flash`, as specified in the accepted plan. Broader quality and hands-free audio performance require more evidence before changing that default.

These results do not prove arbitrary-scene quality, physical camera behavior, motion understanding, speaker feedback control, interruption timing, or a five-second audible response. Repeated variants of one photo are correlated cases. The result is a reproducible integration baseline, not a benchmark of general vision accuracy.

Prices and input support were checked on 2026-11-06. Costs above are actual `usage.costUSD`, not catalog estimates. See the [OpenRouter research note](../docs/research/openrouter.md) for primary sources and data policy limits.
