# Local samples

Use `data/local/` for selected camera captures.
Git ignores that directory.
Use `runs/` at the repository root for raw provider responses and recordings.
Git ignores that directory too.

Use non-sensitive scenes for the first experiments.
Check the frame before sending a sample to a cloud provider.
Record sample identifiers and hashes in the experiment record.
Keep personal details out of committed summaries.

If shared samples become necessary, document their origin, license, and consent before committing them.
